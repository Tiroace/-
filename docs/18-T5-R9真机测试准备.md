## 二、已核实的信息（来自官方文档）

来源：https://developers.weixin.qq.com/miniprogram/dev/devtools/sandbox.html

原文关键句：

> 申请测试号的过程非常简单。只需访问**申请地址**，并使用微信扫描二维码，即可获得为自己分配好的小程序和小游戏测试账号。

**申请地址**：https://mp.weixin.qq.com/wxamp/sandbox?doc=1

拿到 appid 后，官方给的做法是：在开发者工具里新建/修改项目，填入测试号 appid，
点工具栏「预览」按钮即可在真机上预览。

## 三、老板要做的三步（已写成一键脚本）

```powershell
# 第 1 步：浏览器打开，微信扫码
#   https://mp.weixin.qq.com/wxamp/sandbox?doc=1
#   页面会直接给你一个测试号 appid（形如 wx1234567890abcdef）

# 第 2 步：拿到 appid 后跑这个脚本（自动改配置、构建、出二维码）
D:\qiuzhibilei\miniprogram\scripts\gen-preview-qr.ps1 -AppId wx1234567890abcdef

# 第 3 步：手机微信扫生成的二维码
#   二维码在 D:\qiuzhibilei\reports\真机预览二维码.png
```

脚本做的事：
1. 把 appid 写进 `src/project.config.json`
2. 跑 `pnpm build:mp-weixin`（含正式包清理）
3. 调 `cli.bat preview` 生成二维码图片
4. 任何一步失败都给出具体原因和替代方案

**实测**：无 appid 时脚本正确停在第 1 步并打印申请地址（退出码 1），不会瞎跑。

## 六、过程中的坑（记录的）

1. **CLI 用游客模式出码必然失败**，错误是 `不存在此 AppID (code 10)`。这不是故障，游客模式本来就不能真机预览。
2. **PowerShell 5.1 读 UTF-8 无 BOM 的 JSON 会乱码**，导致 `ConvertFrom-Json` 报错。
   脚本里统一改成 `[System.IO.File]::ReadAllText($path, [Text.Encoding]::UTF8)`。
   （和之前 .ps1 本身要存 UTF-8 BOM 是两回事：文件本身要 BOM，读别的文件要显式指定编码。）
3. 搜索「微信测试号申请」基本没有有用结果，**直接查官方文档页面更快**。
