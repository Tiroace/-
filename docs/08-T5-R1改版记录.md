## 五、遇到的问题

### 1. 自动化截图环境当前不可用（阻塞「新旧对比截图」）

现象：`automator.connect` 能连上 `ws://127.0.0.1:9422`，但 `getCurrentPages()` 返回 `[]`，
`mp.screenshot()` 超时；`wx` 对象存在，`reLaunch` 发了也不生效。
已尝试：重开 IDE（`open_wechat_ide.ps1`）、`evaluate` 内用 `wx.reLaunch/switchTab`、分别探活 evaluate/screenshot。

判断：**9422 上的自动化窗口处于空状态**（没加载任何页面），需要重新执行
`cli.bat auto --project dist\build\mp-weixin --auto-port 9422`。这条是测试者管的链路，我没有去重启他的窗口。

**补救方案**：
1. 测试者用 `cli.bat auto --auto-port 9422` 重开自动化窗口后，跑
   `node D:\qiuzhibilei\miniprogram\scripts\shot-pages.mjs` → 输出 `reports/rebrand/*.png`
2. 再跑 `python miniprogram/scripts/make-compare.py` 拼对比图
3. 或者直接在 IDE 模拟器里人工截 5 张

### 2. Sass 弃用警告（不影响构建）

构建日志里有一堆 `DEPRECATION WARNING [legacy-js-api]`，是 uni-app 用的 sass 旧 API，
不是我们的代码问题；等 uni-app 升级会消失。

### 3. `uni.scss` 的变量在小程序端可用，但 `@mixin` 不能跨组件用

scoped 样式里用 mixin 需要每个文件 `@use`，所以我把灯的光晕直接写成具体 `box-shadow`，
没有依赖 mixin（`uni.scss` 里仍保留 mixin 定义供以后用）。

### 4. 广场页是占位

tabBar 有「广场」但功能按 D14 默认关闭，页面显示「正在准备」。
社区 3 个页面在 R3 做，届时把占位换成真页面。

### 5. 「我的」页两个统计字段后端还没有

`checked_count` / `red_count` 契约已定（`/me` 新增），后端还没上，前端先按 0 显示，有值就自动显示。
