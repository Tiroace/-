具体发现

按风险从高到低
入职前收钱套路库匹配
「入职前需交 300 元工装押金，转正后全额退还」

正规公司不会在你入职前收钱。《劳动合同法》第九条规定，用人单位不得以任何名义向劳动者收取财物。

点赞刷单套路库匹配
「主要工作：线上点赞、关注，日结 200–500 元」

刷单是常见的诈骗开头：先给你小额返利，再让你垫付大额任务，钱就拿不回来了。

薪资高得不合常理AI 推理
「储备干部，无需经验，月薪 8000–20000」

不要经验，工资区间却很高，又没写底薪多少、提成怎么算。和岗位要求对不上，面试时问清楚。

岗位名不副实AI 推理
「储备干部，负责电话回访、维护意向客户」

叫「储备干部」，干的是电话销售。不一定是骗局，但可能和你想的工作不一样。

公司信息完整AI 推理
「某某网络科技有限公司，某某区某某路 88 号」

写了公司全称和详细地址，可以去公示系统核实是否真实存在。

问入职前要交任何费用吗？押金、服装费、培训费都算。

问签的是劳动合同吗？试用期多久，交不交社保？
