### 关键经验：怎么判断模拟器加载的是旧包

只连上自动化、能截图，**不足以说明加载的是新包**。要这样验：

```js
// 查一个只有新包才有的节点
wx.createSelectorQuery().select('.ai-notice-row').boundingClientRect()
// null  → 旧包
// 有尺寸 → 新包
```

### 关键经验：什么操作会让自动化窗口加载新包

| 操作 | 效果 |
| --- | --- |
| 在 IDE 里点「编译」 | 加载新包 |
| `cli.bat auto --project ... --auto-port 9422` 重开窗口 | **加载新包**（实测有效） |
| `cli.bat open --project ...` | 在这个会话里没触发重新编译 |
| 只是 `wx.reLaunch` / `switchTab` | 不会重读产物，还是旧包 |

### 操作提醒（给后来人）

`cli.bat auto` 会**替换掉同端口的自动化窗口**。如果测试者正在用 9422，
你起一个 `--auto-port 9423` 会让原来 9422 的会话断开连接。
要共用就统一用 9422，先确认没人在跑断言。
