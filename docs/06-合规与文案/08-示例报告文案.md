# 示例报告文案（首页「示例报告」入口用）

> **【草稿，待律师审核，不得对公众发布】**
> 依据：改版任务书 §6.1「示例报告入口：内置 JSON，内容与设计稿 02 一致，不调接口，不扣次数」、§4.4 报告 JSON v2。
> 起草：产品经理 ｜ 日期：2026-10-31 ｜ 版本：v1.0（R1）
> **本文件里的数据全部是虚构的**：公司名写「某某」、金额与岗位是通用示例，不指向任何真实企业或个人。
> 用途：① 前端做示例报告的 JSON 内容源；② 前端做报告页 mock 的第一份数据；③ 测试做报告页渲染断言基线。

## 一、报告页顶部/底部固定文案（每份报告都要有）

| 位置 | 文案（一字不改） |
| --- | --- |
| 示例报告标识（仅示例） | `示例报告 · 内容是虚构的，不指向任何公司` |
| 报告顶部标识 | **无**（路线令后不再标注生成式内容；只保留「示例报告」标识） |
| 固定免责声明（页脚） | `本报告由系统根据截图文字和规则库自动生成，仅供参考，不构成法律意见，也不代表对任何企业的评价；截图不完整或内容不实都会影响判断，重要事项请自行核实。` |
| 判断不准入口 | `判断不准？告诉我们` |
| 底部按钮 | 左：`提醒朋友` ｜ 右：`再查一份` |

> 免责声明 v2 版比 v1 多了「结合套路库」四个字——因为 v2 结论同时依赖套路库匹配。**v1 那句话作废，全产品统一用上面这句。**

## 三、渲染核对表（前端做完对照这里打勾）

| # | 检查点 | 期望 |
| --- | --- | --- |
| 1 | 结论区背景 | `$red-soft`（红），亮红灯，标题「这份工作，建议先别去」 |
| 2 | 副标题统计 | 「2 项红灯，2 项黄灯，1 项绿灯」——**灰灯不计入这句统计**，另在维度格显示「截图里没提到」 |
| 3 | 6 项检查 | 2 列网格，顺序固定：收费与借贷 / 工作内容 / 岗位名称 / 薪资待遇 / 公司信息 / 合同社保 |
| 4 | 维度短句 | `short` ≤ 6 字，界面不截断 |
| 5 | 具体发现排序 | 红 → 黄 → 绿；同灯色按维度固定顺序 |
| 6 | 来源标签 | 只有两种：`rule`→「规则命中」、`pattern`→「套路库匹配」（`llm` 已废） |
| 7 | 原话引用 | 显示 `context` 整句，`evidence` 高亮（红/黄/绿各自的 `-mark` 色） |
| 8 | 已交了钱区块 | 仅 `overall = red` 显示；**拨号按钮只有 110、96110 两个**；**12333 是按钮下方单独一行文字**「劳动权益问题（欠薪、不缴社保、扣押证件），可拨 12333」，不做拨号键（D21） |

## 四、四份可变体（给测试截图 4 种 overall 用）

任务书 §9 要求报告页 4 种整体结论各截一张图。除本示例（red），另需三份变体，由前端内置 JSON 或后端 mock 提供：

| 变体 | overall | 结论标题 | 结论区背景 | 灯 |
| --- | --- | --- | --- | --- |
| A（本份） | red | 这份工作，建议先别去 | `$red-soft` | 红灯亮 |
| B | amber | 先问清楚，再决定去不去 | `$amber-soft` | 黄灯亮 |
| C | green | **截图里没看到明显风险**（D16） | `$green-soft` | 绿灯亮 |
| D | unknown | 截图信息不够，再补一张 | `$surface` | 三灯全暗 |

**B/C/D 的文案要求**（内容由测试/前端用 mock 造，但措辞必须按这里写）：

- B（amber）：`summary` 不许出现「骗子」，只写「有条信息对不上：…」；副标题例「0 项红灯，2 项黄灯，3 项绿灯」。
- C（green）：**禁止出现**「安全」「没问题」「放心去」。标题固定 **D16「截图里没看到明显风险」**，`summary` 写「截图里没有收费、刷单这类常见写法」。维度里必须有至少 3 项绿灯，允许 1–2 项灰灯。
- D（unknown）：`dimensions` 6 项全部 `none`，`findings` 为空数组，`questions_to_ask` 里必须包含「能不能再截一张带岗位名称和薪资的图？」；页面不显示「具体发现」区块。

## 五、禁用词自检

本示例报告已逐条对照 `05-报告页文案模板与禁用词清单.md` §7.1 一级禁用词：**0 命中**。
特别说明：`reason` 里「不一定是骗局」——「骗局」指**一类手法**，不指任何公司或个人，属允许用法；若律师认为仍需收紧，统一改为「不一定有问题」。
