# 公司核实卡片文案（报告页新增）

> **【产品定稿 v1.0】** 依据《路线调整令》第五节「查公司信息（新增）」：一期从 OCR 文字里提取公司全称，报告里放「核实这家公司」卡片，一键复制公司名，教用户去国家企业信用信息公示系统、黑猫投诉搜索；**不接第三方数据，不爬取**。
> 起草：产品经理 ｜ 日期：2026-10-31 ｜ 版本：v1.0
> 全文无「AI」字样。

---

## 一、卡片出现条件

| 条件 | 表现 |
| --- | --- |
| OCR 文字里提取到「……有限公司」这类**公司全称** | 显示卡片，带公司名 + 复制按钮 |
| 只提取到简称 / 只看到个人微信、手机号，没有全称 | 显示卡片，但**不放复制按钮**，改为引导「先问对方要公司全称」 |
| 完全没提到公司信息（`company` 维度为灰灯） | **不显示卡片**（避免空卡片占位） |

> 提取逻辑由引擎负责（正则匹配 `XX有限公司`、`XX有限责任公司`、`XX股份有限公司`），本文件只管文案。

---

## 二、卡片文案（有全称时）

**卡片标题**：`核实这家公司`

**提取到的公司名**（可长按 / 点复制）：

```
{company_name}
```

**按钮**：`复制公司名`

**复制成功提示**：`已复制，粘贴到下面两个网站就能查`

**正文说明**：

> 光凭截图看不出公司是不是真的。下面两个地方可以自己查一下，几分钟的事。

**查什么（两条，带图标）**：

1. **国家企业信用信息公示系统**
   > 搜公司全称，看它**是不是真的存在**、什么时候成立的、经营范围跟这个岗位对不对得上。
   > 按钮：`复制名字去查`（复制后给一句提示：`已复制，去浏览器打开 gsxt.gov.cn 搜索`）

2. **黑猫投诉**
   > 搜公司名或品牌名，看有没有人反映过收费、押金、欠薪这些问题。
   > 按钮：`复制名字去查`

**底部小字**：

> 这里只是给你核实的方向，我们没法替你判断这家公司好不好。

## 三、卡片文案（只有简称 / 只有个人联系方式时）

**卡片标题**：`核实这家公司`

**正文**：

> 截图里没写公司全称，只有{个人微信 / 手机号 / 简称}，这样就查不到具体是哪家公司。
> 面试前建议先问一句：**「公司全称是什么？」**

**追问按钮**：`复制这句话问 HR`（复制「公司全称是什么？」）

**补充说明**：

> 公司全称是「某某有限公司」这种写法。如果对方说不清、或者只说「不方便透露」，这一项就要多留个心。

## 四、一期不做的（写进代码注释，避免有人自行加）

| 不做 | 原因 |
| --- | --- |
| 不直接展示工商信息（成立时间、经营状态） | 要接企查查/天眼查开放平台，按次付费，二期再评估 |
| 不抓取 BOSS 直聘、黑猫投诉的数据放进产品 | 路线令明确禁止 |
| 不给公司打分、评级 | 触碰名誉侵权红线 |
| 不显示「该公司已被 XX 人投诉」这类聚合结论 | 无数据来源，属编造 |

---

## 五、与报告其他部分的关系

- 卡片位置：**6 项检查之后、「具体发现」之前**（先给整体，再给细节）。
- 与 `company` 维度**不冲突**：维度灯表达「截图里写没写」，卡片表达「写了的话怎么查」。
- 如果 `company` 维度是绿灯（写了全称），卡片正好承接；如果是黄灯（只有个人号），卡片显示 §三 版本。

## 六、自检

- [ ] 有全称 → 显示复制按钮；无全称 → 不显示复制按钮，显示追问话术
- [ ] 公司名不写入日志、不上报，只在用户本地复制
- [ ] 按钮复制的是**纯公司名**，不带前后缀
- [ ] 全文无「AI」、无「评分」「评级」「投诉次数」
- [ ] 两个网站名称写全：`国家企业信用信息公示系统`、`黑猫投诉`

## 七、待确认

1. 是否要在卡片里做**站外跳转**：小程序内不能直接打开外部网址，只能复制 + 提示用户去浏览器；建议**只做复制**，不要做「点击打开」（会触发平台违规）。
2. 「黑猫投诉」是第三方商业平台，引用其名称是否需要授权 — 建议只写名字不写链接，等律师看。
