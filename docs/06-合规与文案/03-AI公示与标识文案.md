## 五、宣传与介绍边界（v2 复核后不变）

| ❌ 禁用 | ✅ 替换 |
| --- | --- |
| 骗子公司 / 黑心企业 | 「这条招聘信息有风险提示」 |
| 100% 识别 / 绝不漏判 | 「帮你发现常见的风险点」 |
| 最准 / 第一 / 最权威 | 「附原话，可核对」 |
| 已帮 10 万人避坑（无数据支撑） | 不写 |
| 曝光 / 打假 / 揭穿 | 「风险提示」 |
| **套路库收录了 5000 条（未核实数量）** | 「套路库里有常见的招聘套路话术」——数量以实际库为准，不编 |
