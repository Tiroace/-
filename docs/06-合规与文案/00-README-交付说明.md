## 三、需要老板拍板 / 律师确认

**A. 老板拍板（阻塞上线或提审）**

1. 主体：公司全称、统一社会信用代码、注册地址、联系邮箱、申诉邮箱、管辖法院（01/02/04 号文档多处占位）；
2. 客服责任人：申诉 7 个工作日答复必须有人真的处理，否则是空头承诺；
3. 套餐价格（周卡 ¥6.9 / 月卡 ¥19.9 / 季卡 ¥39.9）与「虚拟商品不退」口径；
4. 产品正式名称（定名前查商标）；
5. 各留存期限：次数流水 6 个月、日志 6 个月、反馈 1 年、申诉工单 2 年、留样 90 天——是否接受；
6. 加急下架（24 小时内）授权人是谁。

**B. T1 核实（缺一项提审必卡）**

- 服务类目（工具类）资质；激励视频广告位开通门槛；工具类能否开虚拟支付与 iOS 处理；
- ~~主模型备案号~~（**路线令后已不需要**：一期不用生成式模型）；
- 「会员只加次数、不写免广告」是否被判「付费免广告」；
- **求助广场是否需信息发布类资质与安全评估（阻塞社区功能开启）**。

**C. 律师确认（每份文档末尾都列了清单）**

- 未经 HR 同意处理截图内第三方信息的法律依据；
- 免责条款能否对抗名誉侵权主张；
- 「虚拟商品不支持退款」与消保法适用关系；
- 管辖法院写法；是否需要单独的第三方信息共享清单与投诉处理规则；
- **D20 免责声明是否满足律师要求**（现行：「本报告由系统根据截图文字和规则库自动生成，仅供参考，不构成法律意见，也不代表对任何企业的评价；截图不完整或内容不实都会影响判断，重要事项请自行核实。」）；
- **社区规范第 2.2 条「定性词发布时拦截」是否削弱用户正常维权表达**。

## 四、给开发/测试的落地口径（可以直接当验收用例）

1. **文案即验收**：05 号文档 = 报告页字段级文案源；13 号 = 检查规则说明页正文；14 号 = 报告模板话术源（开发者落词库）。前端照此实现，测试照此判。
2. **禁用词做双层过滤**：规则输出层 + 页面展示层，用 05 号 §六 清单；测试对全部页面与测试集输出各跑一次，0 命中。
3. **固定不变的四句话**（不得改字，路线令后第 1、2 句已换）：
   - 「本报告由系统根据截图文字和规则库自动生成，仅供参考，不构成法律意见，也不代表对任何企业的评价；截图不完整或内容不实都会影响判断，重要事项请自行核实。」（**D20 定稿**，全产品唯一版本；含「AI」的旧 D15 版作废）
   - 报告顶部**不再有**「AI 生成 · 仅供参考」标识（整块删除）
   - 高危提醒（**D21**）：110 / 96110 两个拨号按钮；12333 是下方单独一行文字「劳动权益问题（欠薪、不缴社保、扣押证件），可拨 12333」，**不做拨号键**

4. **广告兜底必须有可复现证据**：无填充、断网、拉取失败三种场景，均直接到账 1 次，测试要留日志与截图。
5. **报告可见性**：报告仅本人可见，无公开页、无搜索入口；分享图打码四项（公司名/人名/电话/微信号）。

## 五、已知风险

1. 十五份文档里 `【待老板确认】` 占位较多，**占位未清零前不得对外发布**，提审材料也会被驳；
2. 「暂未发现明显风险」这句是否被认定为对企业背书，需律师判断；如被否，改「截图中未见本清单所列风险点」；
3. 会员「付费免广告」红线的最终判定依赖 T1 核实，在此之前会员页文案按「绝不出现免广告」执行；
4. 申诉 SLA 是承诺，需配客服人力，否则构成对用户的虚假承诺；
5. **社区规范（10 号）整体处于「草稿 + 功能关闭」状态**，任何人不得把广场页文案当作已上线内容对外展示；
6. **品牌名「面试请等等」仍是暂定名**，老板定名与商标查询完成前，对外材料不得写成正式名称；
7. **产品里不得出现「AI」字样**（路线令硬约束）：任何新写文案上屏前用 `12-去AI文案替换清单.md` §六 精确匹配扫一遍；
8. **报告文字全靠模板拼装**：开发者不得在代码里另造句子，模板以 `14-报告模板话术审定表.md` 为准，改模板需产品复签。
