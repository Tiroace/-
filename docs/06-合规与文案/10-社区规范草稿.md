# 社区规范（草稿）

> **【草稿，待律师审核，不得对外发布】**
> **【功能状态：求助广场功能开关默认关闭（`FEATURE_COMMUNITY=false`），本规范不随 R1 上线。资质核实通过、律师审核通过、功能开启后，本规范才在广场页与「我的」可见。】**
> 依据：改版任务书 §11 求助广场；原下派书 §8 法律风险；《网络信息内容生态治理规定》《互联网用户账号信息管理规定》等（具体法条以律师核定为准，本文不编条款号）。

## 一、这个广场是干什么的

- 你觉得一份工作拿不准，可以把**公司名、职位、城市**和你的疑问发出来，让别的求职者给你一些参考。
- 别人可以投「建议去」或「不建议去」，也可以写自己的经历。
- **我们只提供发布和投票的地方，不替任何人评价任何公司。** 所有投票和经历都只代表**其他用户的个人看法**，不是平台结论，也不是事实认定。

**这个广场不做什么（写死）**：
- 没有公司排行榜，没有黑名单页，没有公司总评分；
- 不会把票数换算成对一家公司的评价；
- 不提供「查这家公司靠不靠谱」的查询服务。

## 二、能发什么、不能发什么

### 2.1 能发（请这样写）

- 你**亲身经历**的招聘过程，具体到事实：什么时候、什么岗位、面试说了什么、让你做了什么、要你交多少钱。
- 示例：`「2026 年 10 月投的『储备干部』，面试在某某写字楼，对方让我先交 300 元工装费，说转正退。」`

### 2.2 不能发（发布当场拦截，或提示你改写后重新提交）

| 类别 | 举例 | 处理 |
| --- | --- | --- |
| 定性词（最重要） | 「骗子」「骗子公司」「黑心企业」「无良公司」「诈骗团伙」 | **拦截，提示改成描述事实**；改写后才可提交 |
| 人身攻击、辱骂 | 侮辱性称呼、诅咒、地域歧视 | 拦截 |
| 造谣、无依据结论 | 「这家公司明天就要跑路」 | 拦截，提示补充事实依据 |
| 他人隐私 | 他人手机号、微信号、QQ 号、身份证号、银行卡号、家庭住址、门牌号 | 自动打码；文字里的同类信息替换为 `***` |
| 截图里的敏感信息 | 身份证、银行卡、病历、他人私密照片 | 自动打码，并提示你手动补充打码 |
| 违法有害 | 色情暴力、赌博、涉政、广告导流、拉群刷单 | 拦截 |
| 拉踩与广告 | 「都别去，来我这儿」「加我私聊给你内推」 | 拦截 |

**发布表单会显示的一句话提示（必须显示）**：

> 写事实，不写结论。写「面试要求交 300 元服装费」，比写「这家公司是骗子」有用，也不会给你惹麻烦。

## 三、投票与经历

1. 一个账号对一个帖子**只有一票**：选「建议去」或「不建议去」，可以改，不能重复投。
2. **发帖人不能给自己的帖子投票。**
3. 理由标签选填（我也被要求过交钱 / 岗位和说的不一样 / 面试流程正常 / 其他），标签后台可配置。
4. 显示票数和比例条，**不换算成公司评分**。
5. **新注册未满 24 小时的账号**不能投票、发帖、写经历。
6. 防刷：同一设备或同一 IP 段短时间大量投票会被风控，可疑票不计入展示，但保留记录备查（依法处置用）。

## 四、发布流程：先审后发

1. **敏感词**：敏感词库 + 大模型审核两层，命中直接拦截或提示改写（词库后台可随时增删，不用发版）。
2. **隐私打码**：截图自动打码手机号、微信号、QQ 号、身份证号、银行卡号、人名、门牌号；文字同类信息替换 `***`；**你可以补充打码**。
3. **内容安全**：图片和文字都过平台内容安全检测。
4. **人工审核**：机器审核通过即发布；拿不准的进人工审核。

**展示中的固定提示（每条帖子和经历都要带）**：

> 来自用户分享，只代表个人经历。

## 五、举报

- 每个帖子、每条经历都能举报，理由可选：定性词/辱骂、造谣、泄露隐私、广告导流、其他。
- **同一内容被举报达到 3 次（可配置）先自动隐藏，再人工复核**。
- 举报人信息不向被举报人展示。

## 六、企业申诉（比一般申诉更快）

- 企业**上传营业执照完成认证后**可对帖子提起申诉。
- **目标 24 小时内处理**（一般用户申诉是 7 个工作日，企业涉及商誉，单独加急）。
- 处理结果三选一：**保留 / 修改 / 删除**，并通知发帖人。
- **处理记录长期保存**，供日后查验。
- 申诉入口：广场页底部「企业申诉」+ 小程序「我的」→ 申诉与投诉。

**企业申诉表单字段**：企业名称、统一社会信用代码、营业执照、涉及帖子链接或编号、具体问题、联系方式（仅用于回复）。

## 七、违规处理

| 情形 | 处理 |
| --- | --- |
| 首次发布定性词 | 拦截，提示改写（不计违规） |
| 反复发布定性词、辱骂 | 警告；多次则禁言 |
| 造谣、泄露他人隐私 | 内容立即删除；视情节禁言或封号 |
| 广告导流、拉群 | 删除内容 + 禁言 |
| 情节严重或涉嫌违法 | 封号，保存证据，依法移交 |

## 八、免责说明（广场页与每个帖子详情页底部固定显示）

> 广场内容由用户自行发布，只代表发布者的个人经历和看法，**不代表平台观点，也不构成对任何企业的评价**。
> 投票结果仅供参考。如你认为内容不当，请点击举报或通过企业申诉渠道联系我们，我们会及时处理。

## 九、用户须知（发帖第一屏，必须勾选）

> ☐ 我确认以上是我**真实的经历**，已阅读并同意《社区规范》和《用户协议》。
> 匿名发布（默认开）：发布后其他人看不到你的账号，只显示匿名昵称。

## 十、待律师 / 平台确认（阻塞功能开启）

1. **资质**：用户发布内容 + 投票的社区形态，是否需要**信息发布类增值电信业务许可**、是否需要**安全评估**；
2. **类目**：小程序服务类目需选允许用户发布内容的类目，其资质要求是什么；
3. **实名方案**：「后台实名、前台匿名」的具体实现方式与合规性；
4. **审核义务边界**：先审后发 + 3 次举报自动隐藏，是否足以证明平台尽到管理义务；
5. **定性词拦截**：把「骗子」类词在发布时拦截，是否会削弱用户正常维权表达——需律师给出合规边界；
6. **保存期限**：举报与申诉处理记录保存「长期」是否符合最小必要，建议明确为 2 年。

> 以上任一项未确认前，功能开关保持关闭，广场页面对用户不可见。
