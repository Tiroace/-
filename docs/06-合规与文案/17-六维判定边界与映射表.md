# 六维判定边界与映射表（规则与标注的共同依据）

> **【产品口径 v1.0，已定】** 依据 `DECISIONS.md` D31。
> 起草：产品经理 ｜ 日期：2026-10-31 ｜ 版本：v1.0
> 用途：写规则时定 `dimension`、标样本时定 `dimensions`，两边照这一份来。**先归属、再判等级**，顺序不能反。

---

## 〇、三个基本原则

1. **一事一灯**：一条话术只点亮一盏灯。同一句话牵涉两维时，按 §一 的优先级归属，**不允许两边都点**。
2. **按内容归属，不按可疑度归属**：这句话在说哪个检查项，就归哪一维。可疑度只决定灯的**颜色**（红/黄），不决定灯的**位置**。
3. **灰灯 = 截图里没提到**：不是「没问题」，也不是「归到别的维度去了」。凡是「这句话能归到 A 也能归到 B」，就是归属表没覆盖，应该补表，不能随手挑一个。

---

## 一、优先级（冲突时按这个顺序落灯）

一条话术同时符合多个维度特征时，**取优先级最高的那一维**：

```
fee（收费与借贷） > work（工作内容） > contract（合同社保） > pay（薪资待遇） > title（岗位名称） > company（公司信息）
```

**为什么是这个人 `fee` 最高**：收费与借贷是唯一能直接掏空用户钱包的一维，也是法条最硬的一维（劳动合同法第九条）。同一句话里既有「要交钱」又有别的毛病，先报「要交钱」——用户最需要知道的是这个。

### 1.1 优先级示例

| 话术原文 | 涉及 | 归属 | 为什么不是别的 |
| --- | --- | --- | --- |
| 「可在国家电网/部队文职安排工作，费用 3000 元」 | fee + title | **fee** | 有收费就是 fee；「安排工作」只是名头 |
| 「先在指定 App 上做任务，完成任务后返利 200 元」 | fee + work | **fee** | 要垫钱/返利属收费借贷；work 只描述活干什么 |
| 「试岗 7 天，不合格不结算工资」 | contract + pay | **contract** | 说的是用工关系与报酬规则，不是薪资高低 |
| 「储备干部，实际做电话销售，月薪 8000」 | title + pay | **title** | 岗位名与职责不符是 title 的核心；薪资写得清楚反而不该点 pay |
| 「姓名不方便透露，加我微信详聊」 | company | **company** | 公司信息缺失 |

## 二、六个维度各自的判定边界

### 2.1 `fee` 收费与借贷（优先级最高）

**凡是「钱从求职者口袋出去」的，都归这里**，不管名目叫什么：

| 归 fee | 例子 |
| --- | --- |
| 各类押金保证金 | 押金、保证金、服装押金、设备押金、培训押金 |
| 各类收费名目 | 服装费、体检费、培训费、材料费、建档费、资料管理费、岗位安置费、中介费、介绍费、就业指导费 |
| 借钱与分期 | 培训贷、助学贷、分期付款、先学后付、贷款买车、租车承包 |
| 垫付与返利 | 刷单垫付、任务款垫付、先垫钱再返利 |
| 索要资金凭证 | 银行卡号、验证码、身份证正反面、手持身份证 |

**不归 fee 的**：
- 「工资多少」→ `pay`（钱进兜里，不是掏出去）
- 「从工资里扣」→ 要看扣的是什么：扣服装费/押金 → `fee`；扣社保 → 本来就不该扣，归 `contract`
- 「刷单」这件事本身（做什么活）→ 如果只是描述工作内容、没提垫钱 → `work`

### 2.2 `work` 工作内容（第二优先）

**说的是「这份活具体让你干什么」**：

| 归 work | 例子 |
| --- | --- |
| 刷单、点赞返利、做任务 | 不含垫钱时为 work；含垫钱时升到 fee |
| 拉人头、发展下线 | |
| 下载陌生 App、进 QQ 群领任务 | |
| 境外工作 | 缅甸、柬埔寨、迪拜 + 高薪/包机票 |
| 打字员、手工活带回家 | |
| 职责写得含糊「到岗再定」 | 黄灯 |

**不归 work 的**：岗位名称与实际职责不一致 → `title`（work 只管职责本身写没写清、写的是什么）。

### 2.3 `title` 岗位名称（第五优先）

**只判一件事：名字和实际职责对不对得上**。

| 归 title | 例子 |
| --- | --- |
| 名称很虚但没说实际做什么 | 储备干部、管培生、行政助理（只说名字没给职责）→ 最多黄灯 |
| 名称与职责明显不符 | 「储备干部」+「负责电话回访、维护意向客户」→ 黄/红 |
| 冒用单位名义招人 | 「国家电网安排工作」「部队文职包进」「大厂直签」（**不含收费**时才归这里） |
| 就业歧视 | 限性别、限婚育、限户籍 |

**关键边界**：
- **岗位名可疑但不给职责原文，不给黄灯**。标准是「必须能指出名字和职责哪里对不上」，指不出来就只是「名字不好听」，不构成风险。
- **带收费的「安排工作」归 `fee`**，不归 title。这是本次 60 处差错里最大的一类。

### 2.4 `pay` 薪资待遇（第四优先）

**说的是「给多少钱、怎么给」**：

| 归 pay | 例子 |
| --- | --- |
| 区间跨度离谱 | 5k–30k、底薪 2000 敢报 20000 |
| 无经验却开高薪 | 无经验骑手月入 9000（**判黄，见 D30**） |
| 无法核实的承诺 | 上不封顶、轻松月入过万、日赚、躺赚 |
| 表述模糊 | 只写「综合薪资」、薪资面议、底薪+提成但都说不出比例 |
| 与本岗位门槛不匹配 | 应届生岗位开月薪 3 万 |

**关键边界**：
- **同一句话里若已有收费/垫钱，归 fee 不归 pay**（优先级规则）。
- 「日结工资本身」不违法，只有「日结 + 高薪」或「日结 + 大幅超出同岗位」才算 pay 风险。

### 2.5 `company` 公司信息（最低优先）

**判的是「主体能不能核实」**：

| 归 company | 例子 |
| --- | --- |
| 没有公司全称 | 只写「大公司直招」「知名企业」 |
| 没有地址或地址含糊 | 面试地址待定、约在酒店/咖啡厅 |
| 只留个人联系方式 | 只给个人微信、QQ、手机号，无公司名 |
| 查不到的公司 | 公司名在公示系统查不到 |

**关键边界**：
- 「点名国家电网」这类**有明确单位但用单位名义做承诺**的归 `title`（冒名/名头），不归 company。
- company 的绿灯 = 有全称或详细地址；这不是「这家公司好」，只是「主体能查」。

### 2.6 `contract` 合同社保（第三优先）

**判的是「用工关系与法定待遇」**：

| 归 contract | 例子 |
| --- | --- |
| 试用期问题 | 超过法定上限、试用期不缴社保、试用期工资低于法定 |
| 社保公积金 | 不缴、只写「按国家规定」、转正后缴 |
| 扣押证件 | 扣押身份证、毕业证原件 |
| 无薪试岗 | 试岗 3–7 天不付工资、试岗不合格不结算 |
| 格式条款 | 让你签声明规避责任、签分期协议 |
| 不签合同 | 不签书面劳动合同、只签劳务协议 |

## 三、常见易错归属（本次差错的高发区）

| 话术 | 错误归属 | 正确归属 | 判断方法 |
| --- | --- | --- | --- |
| 「可在国家电网/部队文职安排工作」 | title | **fee**（若收费）/ 仍为 **title**（若仅承诺不含钱） | 先看有没有收费，再定 |
| 「无经验骑手月入 9000」 | title（因为标题是储备干部） | **pay** | 说的是钱，不是名头 |
| 「储备干部，负责电话回访」 | pay | **title** | 说的是职责与名称不符 |
| 「试岗 7 天不付工资」 | pay | **contract** | 是用工规则，不是薪资水平 |
| 「押金 300 元，转正退还」 | company | **fee** | 钱从口袋里出去 |
| 「加微信详聊，公司名不便说」 | work | **company** | 主体不可核实 |
| 「月薪 8000–20000」 | fee | **pay** | 说的是给多少 |
| 「培训费可以分期」 | contract（分期协议） | **fee** | 钱出去，且是收费名目 |

## 四、给开发者与测试者的执行口径

### 4.1 写规则时
- 每条规则的 `dimension` 必须能在 §二 里找到对应行；
- 如果一条规则天然跨两维，**按 §一 优先级取一维**，另一维交给别的规则去覆盖，不要复制成两条规则；
- 新增规则先在本文补归属，再落库。

### 4.2 标注时
- `dimensions` 里每盏灯都必须能指回一句原文；
- 同一段话不得在 `dimensions` 里点亮两盏灯（引擎里可以有多条 finding，但**灯的结论只取优先级最高的那一维**）；
- 标 `none` 的唯一含义是「截图里没提到这一项」。

### 4.3 算一致率时
- 逐维比对，不看顺序；
- 出现「引擎判红、标注 none」时，先在本文 §三 查是否属于归属冲突；属于的按本文改标注，不属于的才是真漏判。

## 五、待确认
