## 〇、统一写法要求（先说清楚，26+50 条都照这个来）

| 项 | 要求 |
| --- | --- |
| `title`（标题） | **4–8 字**，短句，不加标点，不用形容词夸张 |
| `why`（为什么有风险） | 大白话，**≤40 字**，初中文化能懂；不出现「这家公司」「涉嫌违法」这类定性/法律腔 |
| `law`（法条依据） | **只在有明确出处时写**，格式「《劳动合同法》第X条：……」，**不确定的写 null，不许编** |
| `questions`（问 HR 的问题） | 用户能直接复制发给 HR 的**一句话问句**，口语化、必须能问出口 |
| `verify`（核实方法） | **可执行动作**：查哪个网站、搜什么、看什么；不写「请谨慎」这类空话 |
| 主语 | 只能说「这条招聘信息」「对方」「截图里」；**不得出现公司名** |
| 禁用词 | 骗子、骗子公司、黑心、无良、100%、最准、曝光、打假（见 `05` 号文档 §六） |

> **法条只写这四条，其余一律 null**（律师未核定的一律不加）：
> - 《劳动合同法》第九条：用人单位不得扣押劳动者的居民身份证和其他证件，不得要求劳动者提供担保或者以其他名义向劳动者收取财物。
> - 《劳动合同法》第十九条：试用期上限——合同 3 个月以上不满 1 年最长 1 个月，1 年以上不满 3 年最长 2 个月，3 年以上或无固定期限最长 6 个月。
> - 《劳动合同法》第二十条：试用期工资不得低于本单位相同岗位最低档工资或合同约定工资的 80%，且不得低于当地最低工资标准。
> - 《社会保险法》第五十八条：用人单位应当自用工之日起三十日内为其职工办理社会保险登记。

### 补充说明（给写规则的人）

1. **优先级**：类别①③⑧ 最容易误判（正常的「国企招聘公告」「大厂外包」也会命中关键词），写成规则时**必须配反例**，阈值宁紧不松。
2. **`level` 判红的标准**：只要出现「要你先掏钱」或「让你签贷款/分期」，一律红（对应劳动合同法第九条）；纯「名头/说法」类一律黄。
3. **`law` 只引四条**：上表用得最多的是第九条（收费）和第二十条（试岗报酬）；第十九条用于试用期超限（已有 R-PROBATION-01）；第五十八条用于社保（已有 R-NOSOCIAL-01）。类别②④⑥⑧ 里没有直接对应法条的，**一律 null，不许为了凑数硬套**。
4. **`questions` 都可以直接复制发给 HR**，不要出现「质问」「举报」之类的攻击性措辞。
5. 结论：**新建 24 条规则**（红 13 / 黄 11），与原有 26 条规则有 3 条重叠（R-DISCRIM-01 与 R-DISCRIM-02/03、R-TRAIN-02 与 R-CLAUSE-02、R-COMPANY-01 与 R-IMPERSON-02），**重叠的保留原规则 ID，把新的话术补进原规则的 `keywords`**，不要建两条。

## 三、报告拼装规则（给开发者的实现口径）

1. **一条规则命中 → 一条 finding**，`title` 用本表 `title`，`reason` 用 `why`，`evidence` 是命中的 OCR 原文，`dimension` 取规则所属维度，`source = "rule"`。
2. **一个套路命中 → 一条 finding**，`title` 用 `name`（超过 8 字的截到 8 字内或改用短名，见下表补丁），`reason` 用 `why`，`source = "pattern"`。
3. **`questions_to_ask`**：取所有命中项的 `questions` 去重，**最多 5 条**；灰灯维度按 `05` 号文档追问池补齐。
4. **`how_to_verify`**：取所有命中项的 `verify`/`how` 去重，**最多 5 条**。
5. **不生成新文字**：任何情况下不得由程序重新造句子，只能拼接模板。
