## 一、D20 免责声明定稿

### 做法：全项目只留一份

之前报告页、开发页都各自抄了一份，容易不同步。这次统一：

- `common/constants.js` 的 `DISCLAIMER_TEXT` 是**唯一来源**
- 报告页删掉本地 `const DISCLAIMER`，改成 `import { DISCLAIMER_TEXT }` → `const disclaimer = DISCLAIMER_TEXT`

**新增断言**：全项目扫「本报告由系统根据…」出现次数，只允许 `constants.js` 一份
（dev 页的比对基准除外），有副本就红。

## 二、D21 的 12333 改法

**问题**：之前 12333 和 110/96110 一样做成拨号按钮，容易让用户误以为打 12333 能追回被骗的钱。

**改法**：

| 号码 | 形式 |
| --- | --- |
| 110 | 拨号按钮「拨打 110」 |
| 96110 | 拨号按钮「反诈专线 96110」 |
| **12333** | **不做按钮**，两个按钮下方单独一行文字：<br>「劳动权益问题（欠薪、不缴社保、扣押证件），可拨 12333」 |

同时把 `HELP_TIPS` 里原来那条「劳动权益问题，可以拨打 12333 咨询。」删掉，避免和上面那行文案打架。

**新增断言**（`check:report`）：

```
✓ 三个号码齐全：110 / 96110 / 12333
✓ 110 / 96110 是拨号按钮
✓ 12333 不是拨号键（符合 D21）
✓ 12333 标注为劳动权益热线
✓ 12333 标明适用场景（欠薪/不缴社保/扣押证件）
```

`callPhone('12333')` 一旦出现就红，防止以后有人改回去。

## 三、去 AI 验收口径换成产品给的正则

按产品要求改成 `(?<![A-Za-z])AI(?![A-Za-z])`，并且**只扫上屏文案**：

- `.wxml`：先去掉标签，只留标签之间的文字
- `.json`：只取引号里的配置文案（页面标题等）
- **JS 里的变量名（fail / main / detail / aiNotice）不算**

**新增一条反向自检**：`AI_RE.test('本报告由 AI 生成')` 必须为 true，
防止正则写错变成「永远不报」的假绿。

实测产物验证：

```
产物含 labour-tip: true
产物含 12333: true
产物含 劳动权益: true
12333 是否拨号按钮: false   ← 符合 D21
D20 免责声明在 constants: true
```
