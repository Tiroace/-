# 日报模板（每天一条，发群里；**整条 ≤15 行**）

> 依据：老板 2026-10-31 要求 + 2026-11-03 补充：**每天只发两次汇总（上午派活、晚上日报）；日报 ≤15 行**。

## 模板

```
【面试请等等 · 日报 D{N} · {日期}】
一、今天完成了什么（每条带证据路径/数字，≤5 行）
二、明天做什么（≤3 条）
三、老板操作单进度（到第几步/下一步几分钟，1–2 行）
四、额度与成本：今日 {tokens} ¥{cost}；本月 {tokens} ¥{cost}；预警 {无/⚠️}
五、各成员 token 用量与占比：{成员} {tokens}({%}) …；超预算点名：{成员+原因/无}
```

## 纪律

1. **老板待办只写必须本人的事**；其他人能做的，自己决定并记 `docs/DECISIONS.md`，不在日报里问。
2. 数字必须附来源；没有证据的产出不算完成。
3. 卡点超过 30 分钟必须在群里说，由 Chief 当场决定换人还是换方案，不等日报。
4. 每天更新 `docs/STATUS.md` 与 `docs/17-额度与成本.md`（由 `python ops/usage_report.py` 生成）。
5. **不发中间汇报**（除卡点/需老板决策）：每天只在上午派活、晚上日报两个时点发汇总。
6. **复核只抽查关键数字**，不重跑全部测试；全量测试每天固定时间跑一次。
