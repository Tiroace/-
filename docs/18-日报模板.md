# 日报模板（每天一条，发群里）

> 依据：老板 2026-10-31 要求。四项固定，最后一项只列必须老板本人做的事。

## 模板

```
【面试请等等 · 日报 D{N} · {日期}】

一、今天完成了什么
- （按任务包列，每条带证据：命令输出/文件路径/测试数字）

二、明天做什么
- （最多 3 条，按优先级）

三、需要老板本人做的事
- （只列实名/人脸/付钱/签字/扫码；见 docs/老板待办清单.md；没有就写「无」）

四、额度与成本
- 今日：{tokens} ／ 估算 ¥{cost}（明细 docs/17-额度与成本.md）
- 本月：{tokens} ／ 估算 ¥{cost}；预算 {已用% 或「未设预算」}
- 预警：{无 / ⚠️ 剩余不足 20%}
```

## 纪律

1. **老板待办只写必须本人的事**；其他人能做的，自己决定并记 `docs/DECISIONS.md`，不在日报里问。
2. 数字必须附来源；没有证据的产出不算完成。
3. 卡点超过 30 分钟必须在群里说，由 Chief 当场决定换人还是换方案，不等日报。
4. 每天更新 `docs/STATUS.md` 与 `docs/17-额度与成本.md`（由 `python ops/usage_report.py` 生成）。
