## 附 · 「功能说明」栏建议文本（改自产品经理 `06` 号，**去掉不实表述 + 补类目边界**）

```
本小程序是求职辅助工具类产品，核心功能：用户上传 1–3 张招聘信息截图，
程序读出截图中的文字，对照内置的规则库与套路库逐项检查，给出 6 个方面
（收费与借贷、工作内容、岗位名称、薪资待遇、公司信息、合同社保）的风险提示
与核实建议，帮求职者在面试前判断需要核实哪些地方。

1）判断方式：规则引擎自动检查（本地 OCR + 规则库 + 套路库），不使用生成式
   人工智能，不向任何第三方模型服务传输用户截图。同一张截图每次结果一致。
2）服务边界：本小程序不提供职位发布、简历投递、招聘撮合或劳务中介服务；
   仅对用户自行上传的截图内容做风险提示，不提供企业评价、黑名单或排行；
   报告仅上传者本人可见；分享图对公司名、人名、电话、微信号打码。
3）激励视频：用于解锁「自动检查」这一项功能能力，用户主动点击触发，单页一个
   广告位，1 条广告兑换 1 次检查；广告无填充时直接发放次数（有兜底），
   不存在强制观看。任何功能都不要求必须看广告。
4）合规材料：已上线《隐私政策》《用户协议》《检查规则说明页》；申诉入口（企业或
   个人均可提起，企业无需注册即可提交），目标 7 个工作日内答复。
   〔提交前：把这一行改成**实际**已上线的内容，做到什么写什么，做不到的删掉〕
5）数据：截图仅用于本次分析，分析完成后不用于其他用途并按约定期限清理；
   数据境内存储，不出境；不收集手机号与定位。
```
