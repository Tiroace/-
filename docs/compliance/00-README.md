## 三、三条规矩（我自己也照做）

1. **所有结论附官方来源链接**；找不到来源写「待核实」，**不许凭印象下结论**（`99-来源核验` 里把 6 条没取到的都摊开了）。
2. **不写具体法律意见**，只做「规则 → 我们怎么做」的对照；法律判断交律师。
3. 所有文档中文；每条结论同时写**「现在的状态」**，用 ✅/🟡/❌/🔒/❓ 五档区分「做到了」和「只是想好了」。
