# 内测告知与同意书（面试请等等 · 15 人内测）

- 版本：v1（2026-11-03）
- 用途：15 人内测参测前的告知与同意
- 依据：`docs/16-内测与发布节奏.md`——真实招聘截图**必须征得本人同意**，打码后进测试集

---

## 一、给参测人的话（可直接转发）

> 我们要测一个小工具，叫「面试请等等」。你把招聘截图发进去，它帮你看看这份工作有没有坑——比如要不要先交钱、承诺的岗位是不是假的。
>
> 内测期间免费，可能会有 bug，判断也不一定每次都对。**你的反馈比结果更重要**，判断错了请一定点「判断不准」告诉我们。
>
> 有两点要先说清楚：
> 1. 截图里如果有你的姓名、手机、微信，我们会打码后再看，不会外传。
> 2. **如果你愿意把截图留给我们改进工具，需要你单独同意**（见下面第三节）。不同意也完全不影响你参与内测。

## 二、我们怎么处理你的数据

| 项目 | 内测期做法 |
| --- | --- |
| 截图 | 仅用于本次判断，24 小时内删除原图（云端有专门清理任务） |
| 报告 | 只你自己能看，别人拿不到（已做越权测试，A 账号访问 B 的报告必须 404） |
| 姓名/手机/微信 | 进测试集前**必须打码**（姓名、手机号、微信号、身份证、住址、头像） |
| 用途限制 | 不外传、不用于任何商业用途、不做二次分发 |

## 三、截图的单独授权（可勾选，可不勾）

> 这一栏**可以不同意**，不同意照样能参加内测、照样能用工具。

- [ ] **我同意**把我上传的招聘截图（<u>打码后</u>）留作工具改进的测试样本

**如果同意，请确认：**
- [ ] 我确认截图里没有涉及他人隐私的敏感内容（或已自行处理）
- [ ] 我理解打码后仍可能保留岗位名、薪资数字、公司公开名称、招聘平台界面

## 四、运营侧登记表（内部用，不发给参测人）

同意书归集：**个人助理**。每条内测截图进测试集时，下表必须同步填，缺一不可入库。

| 参测人 | 同意状态 | 同意时间 | 打码状态 | 打码人 | 入库编号 | 备注 |
| --- | --- | --- | --- | --- | --- | --- |
|  | 已同意 / 未同意 |  | 已打码 / 未打码 |  | RS____ |  |

**纪律**：
1. **没有同意就不能入库**。宁缺毋滥，少一条样本比多一条来路不明的好。
2. 打码人 ≠ 同意人本人时，打码后要请本人确认一眼。
3. 参测人中途反悔要求删除的，立刻从测试集和留出集剔除，并在本表备注「已按本人要求删除」。

## 五、内测期已知限制（提前说，免得当成 bug 报）

| 现象 | 说明 |
| --- | --- |
| 有些图识别不准 | 规则引擎在真实截图上还在调，这正是内测的目的 |
| 付费功能没开放 | 当前版本暂未开放付费，免费使用 |
| 用时可能偏长 | 识别是本地跑的，图多会慢一些，请耐心等几秒 |
| 上传后可能要等几十秒 | 正常，页面会自动刷新 |

## 六、怎么反馈

1. **判断不准的**：在报告页点「判断不准」，填一句为什么
2. **其他问题**：填反馈表（见同目录 `内测反馈表.md`）
3. 遇到闪退/白屏：截图发群里，注明手机型号和操作步骤
