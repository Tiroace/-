## 一、会员下架：两层一起才叫下架

只把入口藏起来不够。`v-if` 只影响渲染，**文案照样进包**，审核能看到 wxml 里的
「开通会员 / 周卡 ¥」，等于把未开放功能带上了架。所以做了两层：

| 层 | 做法 | 文件 |
| --- | --- | --- |
| **渲染层** | `MEMBERSHIP_ENABLED = false`，`canBuyMember()` / `isMembershipVisible()` 恒 false | `src/src/common/config.js`、`src/src/common/entitlement.js` |
| **构建产物层** | 会员页从 `app.json` 删除 + 删 `pages/member` 目录；QuotaSheet 会员卡用 `#ifdef QBL_MEMBER_ON` 编译期剔除 | `src/scripts/strip-dev-build.mjs`、`src/src/components/QuotaSheet.vue` |

将来主体变更成企业、支付能开了：把 `MEMBERSHIP_ENABLED` 改回 `true`、
`MEMBER_REVIEW_STRIP` 改回 `false`、定义 `QBL_MEMBER_ON`，重新提审即可，业务代码不用再改。

### 改到的页面与文案

| 位置 | 改动 |
| --- | --- |
| `pages/member/index.vue` | 整页不进包 |
| `components/QuotaSheet.vue` | 会员卡（含「开通会员」「周卡 ¥」）编译期剔除；次数用完文案改「明天再来，次数每天刷新」 |
| `pages/mine/index.vue` | 会员条 `v-if="membershipVisible"`；「保留 30 天」改为会员可见时才显示 |
| `pages/index/index.vue` | `gotoMember()` 加兜底；弹窗「看看会员」入口随开关消失 |
| `pages/doc/index.vue` | 用户协议「3. 次数与会员」→「3. 次数怎么获得」，并写明「目前完全免费，没有任何收费项目」；隐私政策「会员保存 30 天」→ 统一 7 天 |

**两条踩坑记录**：

1. 第一版断言直接找 `MEMBERSHIP_ENABLED` 这个常量名，**产物里找不到**——编译期把常量折叠成了
   `!1`，名字都没了。改成判「编译后 `isMembershipVisible` / `canBuyMember` 函数体必须 `return !1`」。
2. 关键页面清单里原本有 `pages/member/index`，会员页下架后这条会永远红。
   已从 must 列表移除，它的缺席改由第 9 组反向锁住。

## 四、真机全流程录屏脚本（第 2 关准备）

`src/scripts/record-flow.mjs`

按派单的 5 步走，每步截图 + 校验 + 生成文字记录：

| 步 | 内容 | 校验点 |
| --- | --- | --- |
| 1 | 登录 | 「我的」页出现用户信息/次数 |
| 2 | 上传截图 | 上传入口与剩余次数可见，留 15 秒给人真机选图 |
| 3 | 出报告 | 结论、6 项检查、D20 免责声明、12333 行都在 |
| 4 | 看广告换次数 | 「看广告」按钮可见可点，留 20 秒给人真机操作 |
| 5 | 次数用完弹窗 | **不得出现**「开通会员/会员服务协议/¥/周卡/月卡」 |

每步都查：无 AI 字样、无时效承诺；截图 <15KB 判为空图。
输出 `reports/record/01-登录.png … 05-次数用完弹窗.png` + `flow-<时间戳>.md` 记录表。

**职责边界**：脚本只「连接」9422，不启动 IDE、不占端口。
端口没人监听时 2 秒内 `exit 2` 并提示找软件测试者（IDE 的 open/auto 已移交给他）。
所以第 2 关跑到这一步的流程是：

```
# 软件测试者先拉起自动化（docs/18 手册）
cli.bat auto --project "...\dist\build\mp-weixin" --port 9420 --auto-port 9422
# 前端跑流程
node src/scripts/record-flow.mjs
```

已验证：`--dry-run` 输出 5 步清单 exit 0；端口空时 exit 2 且提示正确。
**未经真机验证**——要等正式 AppID 到手，脚本本身只做过端口分支和 dry-run 测试。
