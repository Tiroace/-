## 六、过程记录（IDE 两次卡死）

提审截图期间 IDE 自动化连续失败，两段根因不同，记下来免得后面再踩：

1. **64750 被 Tabbit 浏览器占用**：微信开发者工具的 HTTP 服务端口与浏览器撞车，
   所有 CLI 命令报 `IDE may already started at port 64750`。
   解法：彻底 `quit` 后重开，让 IDE 抢回端口。
2. **CLI 记住的端口 9420 与实际不符**：`%LOCALAPPDATA%\微信开发者工具\User Data\...\Default\.ide`
   文件里只有 `9420`，但 IDE 进程当时没起来，CLI 一直去连一条不存在的服务。
   解法：`taskkill /T /F` 清掉全部 IDE 进程 → 确认 9420/9422/64750 都空闲 → 重新 `open`。
   这时 IDE 自己会起在 9420，再 `auto` 就能连上。

另外两个读上屏文本的方法都不可用，最终方案是 `page.$$('text')`：
`getCurrentPages()[...].data` 的键名全是压缩别名、`page.$vm.$el.innerText` 返回空。
`page.$$('text')` 读的是渲染层真实节点，拿到的就是用户看到的东西，正好是提审截图该验的对象。
