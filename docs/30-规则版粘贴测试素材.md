# 规则版「粘贴文字」测试素材（可直接复制进输入框）

> 用途：规则版提审前，把招聘文字粘进小程序首页输入框，验证红/黄/绿三档都能出对。
> 来源：`src/tests/check-rules.mjs` 里自检用的三组样例，**与自检同源**，不是另外编的。
> 老板的 20 份正式答案表另算（每个结论只能由老板标）。

---

## 一、应该出红灯

```
诚招操作工 待遇优厚
月薪8000-30000元，上不封顶，轻松月入过万
入职需交押金300元，服装费自理
工作地点：缅甸，包机票包吃住，月入2万
联系人：薇信 abc123
```

预期：红。应命中「入职前先收钱」「境外高薪」「收入承诺太夸张」，且能看出「薇信」被还原成微信。

## 二、应该出黄灯

```
招聘储备干部 5名
岗位职责：负责电话回访客户，完成销售业绩考核
薪资：底薪3000-8000元，综合薪资按国家规定
要求：无需经验，零基础可培训
公司地址：本市某大厦
```

预期：黄。应命中「岗位名好听，实际可能是销售」「薪资跨度太大」「零经验却能拿高薪」。

## 三、应该出绿灯

```
东风科技有限公司 招聘 前端开发工程师
岗位职责：负责公司后台系统的开发、协助测试、整理技术文档
薪资：15000-18000元/月
试用期3个月，签订劳动合同，缴纳五险一金
工作地点：深圳市南山区科技园某某大厦8楼
```

预期：绿，且**不应有任何发现**。这条专门防「正常岗位被误判」——
「签订劳动合同」「缴纳五险一金」里的「交/缴」不能被当成收费。

## 四、不是招聘内容（不扣次数）

```
这是一张风景照片，上面写着今天天气很好，我去公园散步了，心情不错。
```

预期：提示「没看出是招聘信息，把岗位介绍或和 HR 的聊天整段粘贴进来」，**次数不扣**。

## 五、变形写法（应该仍能认出）

```
入職需繳押 金300元，請加薇信聯絡
月薪 8千到1.5万
```

预期：繁体、空格、「薇信」都能还原；薪资按 8000–15000 解析。

## 附：自检怎么跑

```bash
cd src
node <pnpm.mjs> run check:rules
```
