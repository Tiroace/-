# 小程序后台「用户隐私保护指引」填写内容（规则版 1.0.7 提审用）

小程序用了剪贴板，后台必须申报。以下是按双版本令第二节第 5 条写好的内容，
**由老板在小程序后台「设置 → 服务内容声明 → 用户隐私保护指引」里填写。**

---

## 一、要勾选的隐私类型

- **剪切板**（必填，唯一用到的一项）

其余类型（位置、相册、通讯录、摄像头、麦克风、手机号）**都不勾**——规则版一项都没用到。

## 二、「剪切板」的用途说明（直接复制粘贴）

```
用户点击「一键粘贴」按钮时，读取剪贴板内容，用于把用户复制的招聘信息或聊天记录
填入输入框进行检查。读取只在用户主动点击时发生，不在进入页面时自动读取；
内容不上传服务器，检查在你的手机上完成。
```

## 三、隐私政策存放位置

- 小程序内路径：`我的 → 隐私政策`（规则版文案已写好，见 `docTexts.js`）
- 该页面已包含剪贴板说明：「只有你点击「一键粘贴」时，我们才会读取剪贴板。」

## 四、其他要说清的两点（给审核看）

1. **内容不上传**：规则版不发任何网络请求，没有服务器。
2. **不面向未成年人**：本服务面向求职者，不收集任何身份信息。

---

## 需要老板做的事

1. 登录小程序后台 → 设置 → 服务内容声明 → 用户隐私保护指引
2. 勾选「剪切板」，用途粘贴上面第二节那段
3. 保存并提交

填完之后，规则版 1.0.7 才可以提交审核。
