## 二、微信开发者工具（本机唯一可跑的小程序 IDE）

- 安装路径：`D:\Program Files (x86)\Tencent\微信web开发者工具`
- CLI：`cli.bat`，常用命令：`open`、`auto`（自动化）、`preview`、`upload`、`build-npm`、`close`、`quit`、`login`、`islogin`
- 关键全局参数：`--project <路径>`、`--appid`、`--port <HTTP 服务端口>`、`--lang zh`
- NW 版本：0.54.1（`version` 文件）

给测试者的使用要点：
1. 先在 IDE 里扫码登录一次（`cli.bat login`），自动化与预览都依赖登录态。
2. 打开项目：`cli.bat open --project D:\qiuzhibilei\miniprogram\dist\build\mp-weixin --port 9420`（**必须是编译产物目录**，里面有 `app.json`；开仓库根会报「在项目根目录未找到 app.json」）。
3. 自动化：`cli.bat auto --project <路径> --port 9420 --auto-port 9422`，然后 automator 连 **9422**（不是 9420）。9420 是 IDE 的 HTTP 服务端口，`--auto-port` 才是 WebSocket 自动化端口，连错会报 `check if target project window is opened with automation enabled`。
4. **游客模式 `touristappid` 能不能用，看的是哪个子命令**（2026-11-03 双人实测对齐，此条为准）：
   - `auto`（自动化）：**游客 appid 可用**。`cli.bat auto --auto-port 9422` 输出 `√ Using AppID: touristappid`，9422 正常监听，automator 能连。测试者 E1 报告与本机复测一致。
   - `open` / `preview` / `upload`：**需要真实 AppID**。`project.config.json` 里为 `touristappid` 时，`open` 会报 `code 10 不存在此 AppID`；preview/upload 本就依赖真实 appid。
   - 所以「IDE 不接受游客模式」是**错误说法**，只对 `open`/`preview`/`upload` 成立。排查时先确认自己在跑哪个子命令。
5. **一键脚本**：`miniprogram\scripts\open_wechat_ide.ps1`（前端维护），固定工程目录与端口 9420；`-Build` 先构建、`-Restart` 先 quit 再开。脚本是 UTF-8 with BOM——PowerShell 5.1 读无 BOM 的 UTF-8 会中文乱码并报语法错误。
6. **必须用 CLI 带 `--port` 启动 IDE**：否则 HTTP 服务端口是随机/未开的，automator 连不上。这是之前「自动化不可用」的根因（2026-10-31 02:12 已解决）。

### 2.1 踩坑速查（现象 → 原因 → 解法）

来源：测试者 E1 报告、`reports/真机预览重出码标准动作.md` 与前端 2026-11-03 复测。原文不在此重复，只留结论。

**坑 1：普通方式启动的 IDE，CLI 一律连不上**
- 现象：`cli.bat islogin` / `open` / `auto` 报 `wait IDE port timeout`，且命令常常 exit 0 像「假成功」。
- 原因：双击桌面图标启动的 IDE 没开 HTTP 服务端口（或端口随机），CLI 按固定端口去连必然超时。
- 解法：先 `cli.bat quit`；连不上时用 `taskkill /F /IM "微信开发者工具.exe" /T` 强制结束；再用 `cli.bat <命令> --port 9420` 重新拉起。IDE 有自动重启行为，清理后要立刻用 CLI 拉起，别让它抢回端口。

**坑 2：`project.config.json` 写成带 BOM 的 UTF-8，IDE 读不出 appid**
- 现象：IDE 报「请检查 project.config.json 是否存在及是否有效」，同时显示 `Using AppID: undefined`。
- 原因：IDE 解析该 JSON 时不接受 UTF-8 BOM，BOM 让整个文件解析失败，appid 自然读到 undefined。
- 解法：一律用无 BOM UTF-8 写入，PowerShell 里写 `[IO.File]::WriteAllText($p, $json, (New-Object Text.UTF8Encoding($false)))`；别用 5.1 的默认 `Set-Content`（中文还会变 GBK 乱码）。

**坑 3：自动化能跑、预览却不行，容易误判成「环境坏了」**
- 现象：`auto` 明明通了，`open`/`preview` 却报 `不存在此 AppID`。
- 原因：这三类子命令对 appid 的要求不同——`auto` 接受游客 appid，`open`/`preview`/`upload` 要真实 AppID（见上文第 4 条）。
- 解法：`auto` 用游客 appid 即可；要 `open`/`preview`/`upload` 时，按 `reports/真机预览重出码标准动作.md` 做「注入真实 appid → 执行 → 恢复占位符」，AppID 只走环境变量，不落盘、不打印。
