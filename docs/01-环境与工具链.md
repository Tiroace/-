## 二、微信开发者工具（本机唯一可跑的小程序 IDE）

- 安装路径：`D:\Program Files (x86)\Tencent\微信web开发者工具`
- CLI：`cli.bat`，常用命令：`open`、`auto`（自动化）、`preview`、`upload`、`build-npm`、`close`、`quit`、`login`、`islogin`
- 关键全局参数：`--project <路径>`、`--appid`、`--port <HTTP 服务端口>`、`--lang zh`
- NW 版本：0.54.1（`version` 文件）

给测试者的使用要点：
1. 先在 IDE 里扫码登录一次（`cli.bat login`），自动化与预览都依赖登录态。
2. 打开项目：`cli.bat open --project D:\qiuzhibilei\miniprogram\dist\build\mp-weixin --port 9420`（**必须是编译产物目录**，里面有 `app.json`；开仓库根会报「在项目根目录未找到 app.json」）。
3. 自动化：`cli.bat auto --project <路径> --port 9420`，然后用 miniprogram-automator 连接该端口。
4. 没有正式 AppID 时用游客模式 `touristappid`（`project.config.json` 里 appid 填 `touristappid`），只能本地预览，不能预览到真机/上传。
5. **一键脚本**：`miniprogram\scripts\open_wechat_ide.ps1`（前端维护），固定工程目录与端口 9420；`-Build` 先构建、`-Restart` 先 quit 再开。脚本是 UTF-8 with BOM——PowerShell 5.1 读无 BOM 的 UTF-8 会中文乱码并报语法错误。
6. **必须用 CLI 带 `--port` 启动 IDE**：否则 HTTP 服务端口是随机/未开的，automator 连不上。这是之前「自动化不可用」的根因（2026-10-31 02:12 已解决）。

## 三、缺口（开工前必须知道）

| 缺口 | 影响 | 处理 |

| 抖音开发者工具版本过旧 | 已装 4.5.7（`C:\Users\Administrator\AppData\Local\Programs\@bytedminiprogram-ide`），`douyinide start-ide` 60 秒连不上、直接启动 exe 无进程；CLI 本身可用但连不到 IDE | **2026-10-31 起抖音端暂缓（D10）**，等老板恢复时再升级最新版 |
| ~~微信开发者工具服务端口关闭~~ 已解决（2026-10-31 02:12） | 根因：IDE 没用 CLI 带 `--port` 启动，HTTP 服务端口随机/未开，`.ide-status` 曾为 `Off` | 现在固定 9420、`.ide-status=On`、`islogin` 返回 `{"login":true}`；统一用 `miniprogram\scripts\open_wechat_ide.ps1` 打开 |
| 没有 DeepSeek API key | 引擎模型层无法真实联调 | 模型层做成可替换适配器，先 mock；key 走安全卡片后接入 |
| 没有云 OCR / 内容安全账号 | 真实图片跑不了；只能 mock 文本 | 引擎先按「OCR 文本旁路」设计，接口对齐后替换真实 OCR |
| MySQL 未运行、无 Redis | T4 后端无法起完整链路 | 优先用 Docker 起容器，或改用 SQLite（原型期） |
| 无正式小程序 AppID | 不能真机预览/上传 | 游客模式先跑；AppID 由老板注册后提供 |

## 五、后端原型（T4）运行方式

- 依赖已装进本机 DSH Python 3.12：fastapi、uvicorn、httpx、python-multipart（见 `backend/requirements.txt`）。

- 注意：`/analysis` 目前同步执行引擎，接真实 OCR/模型前必须改异步（见 D5）。
