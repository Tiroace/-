## 1. 三处改动明细（已完成）

### 1.1 端口 80 → 8080

```dockerfile
ENV ... PORT=8080
EXPOSE 8080
CMD ["sh", "-c", "exec python -m uvicorn backend.app.main:app --host 0.0.0.0 --port ${PORT:-8080}"]
```

**关于「端口 8080 或去掉非 root」**：老板原话是二选一，实际**两个都能保留**——
云托管按 `PORT` 环境变量转发流量（官方：容器规格说明里 `PORT` 是约定），
非 root 用户 `qbl` 监听 8080（1024 以上端口不需要特权）完全没问题。
所以保留了非 root 运行（更安全），只把端口改成 8080。

### 1.2 模型构建时打进镜像

```dockerfile
RUN python -c "from rapidocr import RapidOCR; engine = RapidOCR(); ..." \
    && python -c "import rapidocr, pathlib; p = pathlib.Path(rapidocr.__file__).parent / 'models'; print('模型文件数:', len(list(p.glob('*.onnx'))))"
```

**为什么必须构建时下载**：
- 容器运行时若不能联网，首次识别会去下载模型并失败；
- 容器会被销毁重建（缩容到 0、发布新版本），每次重建重下模型既慢又可能失败；
- 固化进镜像层后，运行时零下载。

**构建日志里会打印模型文件数**，可以确认真的下进去了。
