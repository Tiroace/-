> 负责人：运维（数字员工）｜对应任务：D7 前交付第 3 项
> 更新：2026-10-31｜状态：**清单已定，全部需老板本人提交与刷脸**
> 主要依据：[阿里云 ICP 备案前准备概述](https://help.aliyun.com/zh/icp-filing/basic-icp-service/user-guide/overview)；具体省市口径以当地通信管理局与审核员要求为准，**各省可能更严**。

---

## 0. 最重要的一条：服务器、域名、小程序必须同一主体

三个东西的「主体」必须是**同一家公司**，三处任何一处不一致都会卡住：

| 对象 | 主体体现在哪 | 不一致会怎样 |
| --- | --- | --- |
| **云服务器** | 阿里云账号的企业实名认证主体 | 账号个人实名 → 备案时主体对不上，服务码用不了 |
| **域名** | 域名 WHOIS 持有人名称 / 证件号码 | 域名持有人写个人 → 企业主体备案直接被驳回 |
| **小程序** | 微信公众平台注册主体的营业执照 | 小程序主体与备案主体不一致 → 微信侧校验失败，后续支付/认证受阻 |

阿里云官方原文：**「域名已通过实名认证，域名实名信息（持有人名称、持有人证件类型、持有人证件号码）应与拟备案的主体信息一致」**（出处同上）。
微信侧要求：小程序需完成主体信息登记，且与 ICP 备案主体一致；**小程序备案** 是单独的一步（在微信公众平台内提交，主体信息需与 ICP 备案一致）。

> **给老板的一句话**：所有东西都填公司名、用公司营业执照号，不要有任何一处写个人。

## 3. 主体与人员材料

### 3.1 企业主体

1. 营业执照（原件彩色拍照/扫描，文字清晰可辨，四角完整、不裁切）
2. 法定代表人身份证 **正反面** 彩色照片
3. 法定代表人手机号、常用邮箱（需能收验证码）
4. 企业主体联系方式（座机/手机）

### 3.2 网站负责人（可以是法人本人，也可以另指定）

1. 身份证正反面彩色照片
2. 手机号、邮箱
3. **人脸核验**（阿里云 App 刷脸）
4. 若负责人非法人：需要**授权书**（阿里云模板，法人签字 + 公司盖章）

### 3.3 网站信息

| 项 | 填写内容 |
| --- | --- |
| 网站名称 | **面试请等等**（不要带「中国」「国家」「平台」等敏感词，也不要写「AI」） |
| 网站域名 | 待老板确定 |
| 网站服务内容 | 工具类 / 信息查询类（以审核员口径为准，**待核实**） |
| 前置审批 | 本产品不涉及新闻、出版、教育、医疗、药品、文化等前置审批 → **无**（如后续加社区功能需重新评估，见 D14/D23） |

## 4. 流程与时间

```
① 老板企业实名 → ② 买包年包月 ECS（≥3 月，含带宽）→ ③ 买域名并企业实名
   → ④ 阿里云 App 提交备案（填主体/网站/负责人 + 上传材料 + 刷脸）
   → ⑤ 阿里云初审（1–2 个工作日）→ ⑥ 通信管理局审核（各省 1–20 个工作日不等，待核实）
   → ⑦ 备案号下发 → ⑧ 网站底部悬挂备案号并链接到 beian.miit.gov.cn
   → ⑨ 微信侧：小程序主体信息 + 小程序备案（与 ICP 主体一致）
```

- 时间：**通信管理局审核时长各省不同，官方未给统一承诺 → 待核实**。运维按 20 个工作日做排期保险。
- 备案通过前**不要把域名解析到 ECS 对外提供 web 服务**，会被认定为未备案上线。
- 备案期间机器可以开，但 80/443 只允许内网访问。

## 5. 备案后必须做的事

1. 网站底部加备案号，超链接到 `https://beian.miit.gov.cn/`。
2. 备案信息变更（换域名、换负责人、换主体）要**变更备案**，不能拖。
3. 小程序侧同步完成主体信息与备案。
