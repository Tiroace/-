## 二、⚠️ 必须说清的口径：这批不是「真实截图」

路线令要求**真实截图 ≥120 张**。我抓到的是**真实话术文本**，不是真实截图。

因此我用了一个独立的轨道标识：**`track = "real_text"`**

| 轨道 | 含义 | 能否计入「真实 ≥120」 |
| --- | --- | --- |
| `real` | 真实截图（老板实拍 / 公开图） | ✅ 能 |
| `real_text` | **真实权威话术，但非截图** | ❌ **不能** |
| `synthetic` | 合成 | ❌ 不能 |

**为什么这样分**：这 90 条的**文字是真实的**（来自央视、人民日报、成都通报），
但**图片形态是假的**（我套了模板生成）。混标成 `real` 会让「真实 120 张」这个
数字虚高，等于自己骗自己。真实截图仍需要老板手机实拍，或在公开页里找现成图。

## 三、🔴 重大发现：真实话术的识别率只有 44.4%

用引擎跑这 90 条，结果如下：

### 3.1 整体

| 指标 | 数值 |
| --- | --- |
| 完全一致 | **40 / 90（44.4%）** |
| 方向正确（红判成红或黄） | 20 |
| **漏判/错判** | **30** |

### 3.2 维度级命中

| 维度 | 命中 | 说明 |
| --- | --- | --- |
| fee 收费与借贷 | **19/27（70%）** | 词库覆盖最好 |
| title 岗位名称 | 1/3 | |
| work 工作内容 | **0/12** | 完全没覆盖 |
| pay 薪资待遇 | **0/9** | 完全没覆盖 |
| company 公司信息 | **0/21** | 完全没覆盖 |
| contract 合同社保 | **0/18** | 完全没覆盖 |

### 3.3 典型漏判（原话 → 引擎结论）

| 真实话术 | 期望 | 实得 |
| --- | --- | --- |
| 可在国家电网、部队文职、三甲医院等单位安排工作 | red | **unknown** |
| 打着「国企内推」「保录直签」等旗号 | red | **unknown** |
| 要求求职者签署声明以规避前期诱导贷款的违法事实 | red | **unknown** |
| 以「月工资8000元至12000元」高薪招聘员工为噱头 | red | unknown |
| 以资料管理费、体检费、岗位安置费等名目收取各类费用 | red | 未命中 |
| 以岗前培训考核、适应性试岗为名设定3至7天无薪试岗期 | red | unknown |
| 本地岗位已满、推荐外地高薪岗位 | red | unknown |

### 3.4 结论

**现有词库是按「构造样例」写的，对真实骗术话术覆盖严重不足。**
这正好印证了路线令的判断——只有真实素材才能测出真实水平。

**这不是缺陷，是发现**：合成样例上 92.5% 的维度准确率，在真实话术上只有 44.4%。
**建议把这份清单直接交给开发者，作为规则 v1 的补词依据。**

## 五、给开发者的规则补词建议（基于本批真实话术）

必须新增的高频真实话术模式：

| 模式 | 原话示例 | 维度 |
| --- | --- | --- |
| 关系户 / 内推承诺 | 保录直签、国企内推、有关系、送钱就能入职、付费内推 | company |
| 单位点名承诺 | 安排进国家电网 / 部队文职 / 三甲医院 | fee |
| 异地引流 | 本地岗位已满、推荐外地高薪岗位、已招满去省外 | work |
| 无薪试岗 | 试岗期 3–7 天、考核不合格辞退、不付试岗工资 | contract |
| 多名义收费 | 资料管理费、体检费、岗位安置费、服装费 | fee |
| 租车陷阱 | 不租车卖车为诱饵、租车承包合同、收押金 | fee |
| 格式条款陷阱 | 违约不退费、高额违约金、实训带教协议 | contract |
| 冒名招聘 | 冒用用工企业名义、用工主体不符 | company |
| 高薪诱饵 | 无经验月入9000、月工资8000至12000 | pay |
| 就业歧视 | 特定户籍、少数民族名额已满 | title |
