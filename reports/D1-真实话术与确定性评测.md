## 四、真实话术的价值：暴露出真实覆盖缺口

同一套引擎：

- 构造样例上 **100%**
- 真实话术上 **42.7%**

**这说明现有词库是按「自己编的样例」写的。** 真实骗术里最高频的几类，一条都没覆盖：

| 缺失模式 | 真实原话 |
| --- | --- |
| 关系户承诺 | 保录直签、国企内推、有关系送钱就能入职 |
| 单位点名 | 安排进国家电网、部队文职、三甲医院 |
| 异地引流 | 本地岗位已满、推荐外地高薪岗位 |
| 无薪试岗 | 岗前培训考核、适应性试岗 3–7 天 |
| 多名义收费 | 资料管理费、体检费、岗位安置费 |
| 租车陷阱 | 不租车卖车为诱饵，收押金/绑自动扣款 |
| 格式条款 | 违约不退费、高额违约金、实训带教协议 |
| 冒名招聘 | 冒用用工企业名义、用工主体不符 |
| 岗位造假 | 把保安岗包装成公安辅警、3 个月转正直签 |
| 竞价收费 | 向合作单位收 200–700 元广告费/信息推广费 |

**建议：把这 50 条真实话术直接作为规则 v1 的开发依据**，而不是等做完再测。
