## 二、根因一：报告结论按随机 hash 取模，不可指定

`services\mock.js`（构建产物实读）：

```js
const i = ["red","amber","green","unknown"];
const R = function(seed){
  let n = 0; const a = String(seed || "");
  for (let r = 0; r < a.length; r += 1) n = (n + a.charCodeAt(r) * (r + 1)) % 9973;
  return i[n % i.length];
}(...)
```

`seed` 来自每次上传图生成的随机 hash：`"h-" + 长度 + "-" + random(36,8)`。
**每传一张图随机出一种结论，换图也无法指定。**

模拟 20 万次（复刻同一算法）：

| 结论 | 概率 |
|---|---|
| red | 24.83% |
| amber | 25.26% |
| green | 25.06% |
| unknown | 24.85% |

凑齐四种各一张所需上传次数：**平均 8.3 次、中位 7 次、90 分位 13 次、最坏 36 次**。
且每次扣 1 次额度（初始 3），要靠广告兜底反复补，效率极低。

## 三、根因二：第 10 张只有 red 能满足「两种来源标签各 1 次」

逐份解析 `common\exampleReports.js`（静态数据，mock 原样返回）：

| 报告 | 维度灯 | source=rule | source=pattern | 公司全称 |
|---|---|---|---|---|
| red | fee=red，其余 none | 2 | **1** | 无 |
| amber | pay=amber，company=green | 2 | **0** | 无 |
| green | pay=green，company=green | 2 | **0** | 无 |
| unknown | 6 项全 none | **0** | 0 | 无 |

- 第 10 张要求「**至少 1 个灰灯 + 两种来源标签各出现 1 次**」→ **只有 red 报告满足**（它有 5 个灰灯 + rule×2 + pattern×1）。
- 但 red 只有 25% 概率，且**与第 5、6 张是同一张报告**——可以一次截三张（5/6/10），但都得先把 red 刷出来。

## 四、根因三：第 11 张现在截不出来

- 报告页公司卡片是 `v-if="companyName"`，`companyName` 靠正则从截图文字里提取：
  `[\u4e00-\u9fa5（）()]{2,30}?(有限责任公司|股份有限公司|有限公司|分公司|集团|工作室|个体工商户)`。
- **mock 的四份示例报告都没有 `company` 字段，findings 文本里也没有公司全称结构** → 卡片不渲染。
- 06 号 §三还要求「**无公司全称时显示『复制这句话问 HR』**」，检索源码与产物**没有这个 `v-else` 分支**——只有 `v-if`，没有回退。

## 五、建议（需拍板）

| 方案 | 做法 | 代价 | 评价 |

1. 第 11 张「无公司全称 → 复制这句话问 HR」是否仍要；若要，需开发补 `v-else` 分支。
2. 若不想改代码，是否接受**第 10 张与第 5、6 张同用 red 报告**（一次刷出、一次截三张）。
