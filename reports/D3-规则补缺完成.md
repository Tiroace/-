## 改了什么

### 1. 修了一个**真 bug**：否定词的生效范围

`engine/lexicon.py::_negated()` 原来只看命中点前 10 个字，不论是哪个分句：

```python
window = text[max(0, start - 10) : start]
return any(n in window for n in negations)
```

「不负责装卸、不租车卖车、不收取费用，综合月收入 9500」里，前面的「不收取」把后半句的高薪诱饵也否定掉了——
真实话术里这类**先声明不收费、再报离谱高薪**的写法很常见，等于把最常见的骗术样本放过。

改成按分句判定：句号/分号/换行为硬边界；逗号、顿号分隔的并列项，否定词只有**贴在项首**（不/无/未/没/免）时才算否定这一项。
「无内推名额」「不收费」这类词本身就是否定，仍然生效；「不收取费用，月入 9500」只否定费用，不影响高薪判定。

### 2. 「以…为名」一类明确骗局句式升红

新增/补强 `escalate_regex`（规则本身仍按名头类判黄，句式明确才升红）：

- `R-TRIAL-02`：以「岗前培训考核 / 适应性试岗」**为名**
- `R-TRAIN-02`：「交培训费**才能入职**」
- `R-BAIT-01`/`R-BAIT-03`：模板化高薪诱饵（无经验 + 月入 X；综合 9500 至 13500）
- `R-REMOTE-01`：「本地已满、推荐外地」且带「高薪/包吃包住/日结/万元」；「以已招满为由」

### 3. fee / company 侧补真实话术

`R-FEE-MULTI-01/02`（就业介绍费、分批次收取）、`R-CAR-01`（租车承包押金）、`R-CLAUSE-02`（实训带教协议）、
`R-COMPANY-01`、`R-IMPERSON-01`（冒用他人名义、公示用工主体与实际不符）。
