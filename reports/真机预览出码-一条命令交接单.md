# 真机预览出码 · 一条命令交接单

> 给个人助理：你自己随时出码，不用等我。
> 实测：**连续跑 3 次全部成功**，单次 18–24 秒。

---

## 一、一条命令（复制即用）

**不需要切目录，任何地方执行都行：**

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File D:\qiuzhibilei\tests\support\wx-preview-qr.ps1
```

**参数一个都不用传。** 默认值已指向正确位置（`src\`，非旧目录 `miniprogram\`）。

---

## 二、跑完看什么

正常输出应该是这样（5 行）：

```
appid injected OK
cli exit=0 timeout=False elapsed=21.5s
  √ Using AppID: [secret]
  √ preview
placeholder restored: True
appid plaintext leaks: 0
QR IMAGE: D:\qiuzhibilei\reports\preview-qr-20261103-064313.jpg (46924 bytes)
```

**关键三行：**
- `√ preview` —— 出码成功
- `placeholder restored: True` —— appid 已恢复占位符（必须为 True）
- `appid plaintext leaks: 0` —— 全仓无明文（必须为 0）

**二维码落在**：`D:\qiuzhibilei\reports\preview-qr-<时间戳>.jpg`
（470×470 的 JPEG，纯二维码，无文字水印、不含 appid）

## 三、脚本自己会做的事（你不能代替的部分，它已经做了）

| 步骤 | 说明 |
|---|---|
| 1 | 从环境变量 `$env:DSH_SECRET_WX_TEST_APPID` 读 AppID，**全程不打印** |
| 2 | **无 BOM** 写进 `src\dist\build\mp-weixin\project.config.json` |
| 3 | 自动清掉残留的微信开发者工具进程（`quit` 不可信，改用强杀） |
| 4 | 调 `cli.bat preview -f image -o <jpg>` 直接出图（不是字符画） |
| 5 | **无论成功失败**，`finally` 里都恢复 `touristappid` 占位符 |
| 6 | 全仓扫 AppID 明文，必须 0 命中 |

**这些都不需要你手动做**——所以答案是「你能代替我做全部」。

---

## 四、你唯一要注意的

| 情况 | 处理 |
|---|---|
| 二维码过期（老板扫提示失效） | **再跑一次那条命令**，20 秒出新码 |
| 报 `wait IDE port timeout` | 先跑一次 `Get-Process 微信开发者工具` 看有没有残留，有就强杀再跑；**大多数时候重跑一次就好** |
| 报 `DSH_SECRET_WX_TEST_APPID is not set` | 说明当前会话没有这个环境变量，换一个有权限的会话或找我 |
| 看到 `note: port 9420 currently listening` | **不用管**，那是 CLI 刚拉起的 IDE 自己占的 |
